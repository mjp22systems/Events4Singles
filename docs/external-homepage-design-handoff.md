# Events4Singles External Homepage Design Handoff

Last updated: 2026-08-13

## Purpose

Events4Singles needs a professional homepage design produced outside the current code agent workflow. The current app has usable data, routing, listing templates, SEO direction, and legacy assets, but the homepage visual design should be handled by a specialist designer, a visual website builder, or a design-first AI tool.

The external output should be a responsive homepage design for the content area between the existing site header and footer. Keep the current header, dropdown navigation, footer, listing cards, category pages, city pages, and listing detail pages intact unless a separate redesign brief is approved.

## Design Boundary

The designer/agent should design only the homepage main content area:

```html
<main id="site-content" class="e4s-home-new">
  ...
</main>
```

Do not redesign:

- fixed top header
- dropdown navigation
- global footer
- listing card component internals
- city/category listing page layouts
- listing detail page layout
- database schema

The homepage can reuse listing cards for a promoted listings section, but should not restyle the global listing card unless a separate component variant is created.

## Brand and Audience

Events4Singles is an Australian singles events directory with legacy trust. It is not a nightclub landing page, not a dating app, and not a luxury matchmaking brand. It should feel:

- established
- friendly
- local
- useful
- human
- trustworthy
- easy to browse

Avoid generic startup SaaS style, huge empty hero sections, abstract blobs, AI-looking gradients, fake people/product claims, and over-designed marketing copy. The site is a directory first, with editorial/resources and advertiser monetisation layered in.

## Homepage Jobs

The homepage should do five things quickly:

1. Help visitors find singles events by location.
2. Help visitors browse event/service categories.
3. Reintroduce legacy content hooks: dating advice, singles news, success stories, and the events calendar.
4. Promote advertising options for event organisers and singles businesses.
5. Start building a member/newsletter database for future giveaways, updates, and offers.

## Deliverable Required From External Tool/Designer

Preferred deliverable:

1. Desktop and mobile homepage mockups.
2. Exact typography scale, spacing scale, colours, and section order.
3. HTML/React structure using semantic class names.
4. CSS scoped only under `.e4s-home-new`.
5. Notes for assets used and any generated images.

Acceptable deliverable:

- Figma design with auto layout and named layers.
- Framer/Webflow design export as visual reference, then rebuilt manually in the Next.js app.
- React/Next.js component with plain CSS, if generated cleanly.

Do not deliver:

- A fully separate hosted website that replaces the current app database.
- A design that requires moving the whole Events4Singles site into Wix/Webflow/Framer unless that is a deliberate platform migration decision.
- CSS that changes global header/footer/listing styles without approval.

## Tool Options Researched

### Best fit for visual design exploration: Framer

Framer currently positions itself as a canvas-native design agent where changes are visible and editable, with CMS, hosting, SEO, and agent-based design/code assistance. It is likely the strongest option for quickly generating several polished homepage concepts that can be judged visually before implementation.

Source: https://www.framer.com/

### Best fit for structured marketing site production: Webflow plus Relume

Webflow is strong for visual CMS and SEO/AEO-oriented marketing sites. Relume can generate sitemap, wireframes, style guides, and page copy, then export to Webflow, Figma, or React. This is useful if the priority is structure plus a professional designer polishing the result.

Sources:

- https://webflow.com/
- https://webflow.com/integrations/relume

### Best fit for non-technical all-in-one site generation: Wix Studio / Wix AI

Wix AI can generate a business-ready site from a prompt and includes drag-and-drop editing and business tools. This may be useful for inspiration or a quick standalone marketing site, but it is not the cleanest fit if the existing Next.js database-driven directory remains the source of truth.

Source: https://www.wix.com/ai-website-builder

### Best fit for conservative template quality: Squarespace Blueprint AI

Squarespace Blueprint AI is a guided design system that creates a tailored starting point with curated design choices. It may produce more restrained and coherent layouts, but is less suitable as a direct implementation path for the existing Next.js directory.

Source: https://www.squarespace.com/websites/ai-website-builder

### Best fit for Figma-to-code workflow: Builder.io Visual Copilot

If a real Figma design is produced first, Builder.io Visual Copilot can convert Figma selections into React, Vue, Svelte, Angular, or HTML with styling options including plain CSS and Tailwind. This is a better path than asking a code agent to invent design from scratch.

Source: https://www.builder.io/blog/figma-to-code-visual-copilot

### Best fit for developer-side UI generation: v0

v0 can generate working app UI and define colours, typography, and reusable styles. It is useful for producing React/shadcn-style interface concepts, but it may still need a strong design brief and human visual review.

Source: https://v0.app/

## Recommended Workflow

1. Use Framer or Relume/Figma to produce 2 to 3 homepage visual concepts.
2. Pick one direction visually before code.
3. Convert the chosen design into a scoped React homepage component.
4. Implement CSS only under `.e4s-home-new`.
5. Capture current-site screenshots for the advertising page examples after the homepage style is approved.
6. Build and screenshot QA desktop/mobile before deploying.

## Success Criteria

- Looks like a real Australian directory homepage, not a code-generated table layout.
- Works on mobile without horizontal clipping.
- Uses real links and real data.
- Does not disturb the existing listing/category/city templates.
- Makes advertising and newsletter paths visible.
- Leaves the design system clear enough that future admin and advertising pages can share it.
